What is DevKit.lk?

DevKit.lk is an all-in-one frontend utility tool built specifically for web developers and UI/UX designers. It helps you visually design common UI components—like Buttons, Cards, and Badges—and instantly generates clean, ready-to-use CSS or Tailwind CSS code.

⚡

Saves Coding Time

Instead of manually typing and testing CSS properties like border-radius, padding, and box-shadows, you can adjust sliders and get the exact code in seconds.

👁️

Real-Time Live Preview

See your design changes instantly as you move the sliders. Test how your components look in both Dark Mode and Light Mode before copying the code.

🔄

CSS & Tailwind Support

Switch effortlessly between standard Vanilla CSS and Tailwind CSS utility classes with a single click, making it suitable for any frontend project.
